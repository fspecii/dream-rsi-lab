The function parses the query string, handling URL decoding (plus to space, percent escapes) and preserving blank values and repeated keys. It first checks for a leading '?' and removes it if present. Then, it splits the string by '&' to get individual key-value pairs. For each pair, it splits by '=' to extract the key and value. If the key already exists in the result dictionary, the value is appended to the list. Otherwise, a new entry is created with the value as a list. A try-except block handles potential ValueError exceptions that may occur if the input string is malformed.
