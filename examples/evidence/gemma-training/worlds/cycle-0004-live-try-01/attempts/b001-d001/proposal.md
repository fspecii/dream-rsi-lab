The function sorts the intervals by their start times. It then iterates through the sorted intervals, merging overlapping intervals into a single interval. If an interval does not overlap with the last merged interval, it is added to the merged list. Otherwise, the end time of the last merged interval is updated to the maximum of its current end time and the end time of the current interval. This ensures that all overlapping intervals are combined into a single interval, and the result is sorted by start time. The edge case of an empty input is also handled by returning an empty list.
