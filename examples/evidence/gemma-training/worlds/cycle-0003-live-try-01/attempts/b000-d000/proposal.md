The function first handles the edge case of an empty input list. Then, it sorts the intervals based on their starting points. It iterates through the sorted intervals, merging overlapping or touching intervals into a single interval. If an interval overlaps with the current merged interval, the end of the current interval is updated to the maximum of the two ends. If an interval does not overlap, the current merged interval is added to the result, and the current interval is updated to the new interval. Finally, the last merged interval is added to the result.
