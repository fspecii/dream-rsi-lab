This solution utilizes a min-heap to efficiently merge overlapping intervals. The heap is initialized with the intervals sorted by their start times.  Each interval is popped from the heap, and if it overlaps with the last merged interval (or if no intervals have been merged yet), it's merged. Otherwise, the last merged interval is updated to include the current interval's end time. This approach has a time complexity of O(n log n) due to the heap operations, where n is the number of intervals. The space complexity is O(n) to store the merged intervals and the heap.
